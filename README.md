# 🌸 Desktop Buddy

A custom AI desktop companion built from scratch — designed, illustrated, and voiced personally. She lives on my desktop, walks around, and helps me stay on top of my day with motivational prompts and personalized notifications.

## ✨ Features (planned)

- 🎨 **Original custom-illustrated character** — 17 sprite poses across multiple directions and expressions
- 🎙️ **Custom voice clips** — 14 personally recorded audio responses
- 🧠 **Agentic intelligence** — powered by Claude API for contextual, dynamic messages
- 📅 **Google Calendar integration** — meeting reminders surface as in-character notifications
- 📧 **Gmail integration** — priority email alerts
- 🌅 **Daily greetings** — personalized morning prompts on laptop wake
- 🐧 **Built for Linux** — Pop!_OS / COSMIC desktop native

## 🛠️ Tech Stack

- **Python** (PyQt6 for desktop sprite rendering)
- **Anthropic Claude API** (agent brain)
- **Google Calendar API + Gmail API** (data sources)
- **APScheduler** (recurring task automation)
- **pygame-ce** (audio playback)
- **Audacity + Gemini** (asset creation workflow)

## 🎯 Why I built this

This project sits at the intersection of three things I care about:
- **Creative production** (illustration, voice, design)
- **AI agent design** (autonomous, recurring, reviewable workflows)
- **Personal productivity** (overcoming job search overwhelm with warmth, not robotic notifications)

It's also a portfolio demonstration of an end-to-end AI workflow — from character design through agent orchestration.
